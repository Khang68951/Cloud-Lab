## Lộ trình scale trong bài talk của AWS

1. Một instance cho mọi thứ.
2. Tách database sang dịch vụ được quản lý (RDS).
3. Thêm load balancer, nhiều instance, **nhiều AZ**.
4. Giảm tải đọc: **CDN** cho nội dung tĩnh, **cache** cho dữ liệu nóng, read replica.
5. Auto Scaling; chuyển phần dữ liệu phù hợp sang DynamoDB.
6. Tách service, thêm queue, rồi mới tới sharding.
